# SOL · System of Life

Sistema de evolução pessoal inspirado em Solo Leveling: missões diárias, XP, níveis, atributos, classes e bosses aplicados à vida real.

App web instalável (PWA) para Android e iOS. Os dados ficam salvos só no aparelho.

**Acesse:** https://tassiolirgon.github.io/sol/

## Instalar no celular
- **iPhone:** abra no Safari → Compartilhar → Adicionar à Tela de Início.
- **Android:** abra no Chrome → menu ⋮ → Instalar app.

## Desenvolvimento
```bash
npm install
npm run dev     # servidor local
npm test        # testes do motor de progressão
npm run build   # build de produção
```

A especificação completa do produto está em [SPEC.md](SPEC.md).
